# Códigos postais belgas

`belgian-postcodes.json` contém códigos postais e nomes de localidades deduplicados a partir dos dados de bpost publicados pelo [portal federal de dados abertos da Bélgica](https://data.gov.be/fr/datasets/httpswwwodwbbeexploredatasetcode-postaux-belge), sob a licença [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). O [CSV de origem](https://www.odwb.be/api/explore/v2.1/catalog/datasets/code-postaux-belge/exports/csv?use_labels=false) foi consultado em 24 de novembro de 2026. Foram mantidas as colunas de código postal e localidade.
